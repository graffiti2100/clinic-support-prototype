# 診間支援展示原型

線上展示：https://graffiti2100.github.io/clinic-support-prototype/

手機或電腦可以直接以瀏覽器開啟。包含共同首頁、醫師診間 1／2／3、跟診支援登入、人力分析範例與 13 個展示情境。

所有姓名、職編與診間數據均為模擬資料，重新整理會重設，不同裝置不會同步。這不是正式工作站。

「實際體驗」連到獨立 Railway 推播服務：允許通知後可安排15秒後發送至目前裝置。iPhone 請先加入主畫面並從主畫面開啟（iOS 16.4 以上）。電腦瀏覽器支援時可開啟真正的置頂工作站。只發送手動安排的測試，不發送診間需求；訂閱24小時到期，停止通知會撤銷訂閱並取消待發工作。

`index.html`、`sw.js`、manifest 與圖示由 GitHub Pages 從 main 分支根目錄發布。通知體驗需要線上 HTTPS 網址；後端金鑰及訂閱不保存在此儲存庫。
