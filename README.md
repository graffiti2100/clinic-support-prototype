# 診間支援展示原型 v1.01

線上展示：https://graffiti2100.github.io/clinic-support-prototype/

畫面與正式版 v1.01 使用相同的主要視覺元件、手機排版及置頂小視窗。診間頁採大型狀態卡與人員雙欄配置；分析頁呈現1線團隊可支援／無法支援圓環圖，以及上午08:30起7柱、下午13:30起5柱的半小時支援與等待圖。柱狀圖置於各卡片的圓環圖與統計數字之間，採綠色與暖橘、連續柱形；滑鼠停留或手機點按可查看時段數值。所有姓名、七碼職編、診間與分析資料均為模擬，重新整理會重設，不同裝置不會同步，也不會寫入正式工作站。

從最上方標題列展開「展示設定」，可切換9個情境；在手機或電腦點擊設定外的空白處即可收合：

- 00 共同入口
- 01 平時：無需求
- 02 診間正在等待
- 03 人員已承接
- 04 全員忙碌
- 05 1線全不可用
- 06 多診同時等待
- 07 醫師代為結束
- 08 換手支援

登入、註冊及人力分析可從「觀看頁面」或共同首頁開啟，但不另列為情境。展示職編預設為 `1150001`，其他人員為 `1150002` 至 `1150004`；前三碼以民國入職年示意。

展示設定也提供真實通知測試及支援瀏覽器的置頂小視窗。通知測試約4秒後由 Railway 推播後端發送，冷卻30秒；只傳送測試排程，不傳職編、姓名或展示診間需求。iPhone 需先加入主畫面並由主畫面開啟。

GitHub Pages 從 main 分支根目錄發布 `index.html`、Service Worker、manifest 與圖示。
