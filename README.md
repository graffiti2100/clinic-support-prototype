# 診間支援展示原型 v1.01

線上展示：https://graffiti2100.github.io/clinic-support-prototype/

畫面與正式版 v1.01 使用相同的主要視覺元件、手機排版及置頂小視窗。診間頁採大型狀態卡與人員雙欄配置；分析頁呈現1線團隊可支援／無法支援圓環圖，以及上午08:30起7柱、下午13:30起5柱的半小時支援與等待圖。柱狀圖置於各卡片的圓環圖與統計數字之間，採淡綠與淡杏色、等寬留白柱形；滑鼠停留或手機點按可查看時段數值。所有姓名、七碼職編、診間與分析資料均為模擬，重新整理會重設，不同裝置不會同步，也不會寫入正式工作站。

從最上方標題列展開「展示設定」，可切換9個情境；在手機或電腦點擊設定外的空白處即可收合：

- 00 共同入口
- 01 平時：無需求
- 02 診間正在等待
- 03 人員已承接
- 04 全員忙碌
- 05 1線全不可用
- 06 多診同時等待
- 07 醫師代為結束
- 08 交換線別

登入、註冊及人力分析可從「觀看頁面」或共同首頁開啟，但不另列為情境。預設職務登入可選諮詢櫃台、檢驗櫃台、支援人員；「職編登入」保留原方式。展示職編預設為 `1150001`，其他人員為 `1150002` 至 `1150004`；前三碼以民國入職年示意。

我的狀態與置頂小視窗可換線、提議交換線別；對方同意後才交換，承接中的任務不變。情境08可切換雙方身分體驗同意、拒絕及撤回。移除任務接手與替換2線提示；醫師確認到場不再指定線別。響鈴優先可用1線，沒有可用1線則提醒可用2線；兩線皆無可用人力時提醒忙碌者。1線有空但呼叫滿30秒未承接，擴大至未承接的2線，包含忙碌者。

展示設定也提供真實通知測試及支援瀏覽器的置頂小視窗。通知測試約4秒後由 Railway 推播後端發送，冷卻30秒；只傳送測試排程，不傳職編、姓名或展示診間需求。iPhone 需先加入主畫面並由主畫面開啟。

GitHub Pages 從 main 分支根目錄發布 `index.html`、Service Worker、manifest 與圖示。

2026-09-15：醫師主頁與置頂小視窗可一鍵確認人員到場（承接者未指定）及結束支援。分析卡片分別顯示支援時間佔比與最大等待，取消亦列入等待；執行紀錄每頁10筆，可前後翻頁，含取消與醫師確認到場。所有資料仍為示範，正式資料不受影響。
